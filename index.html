LexDoc — Sistema de gestión legal

uso real

Plataforma para la gestión de casos y documentos de un despacho jurídico, desarrollada bajo contrato de prestación de servicios para Turizo Lawyers Enterprise S.A. Tres perfiles con permisos diferenciados — administrador, jefe de firma y abogado — donde cada abogado accede únicamente a los casos que le fueron asignados. Incluye carga de documentos y alertas de vencimiento de plazos procesales.

ParkSystem — SaaS para parqueaderos

demo pública

Sistema multi-empresa para la operación diaria de parqueaderos. Varias empresas cliente trabajan sobre la misma base de datos con aislamiento total de su información: ninguna consulta devuelve registros de otra empresa. Cubre ingreso y salida de vehículos con cálculo de tarifa, turnos de caja con conciliación por método de pago, mensualidades, reportes exportables a Excel y respaldos automáticos de la base de datos.

MediAssist Rural

en producción

Asistente de orientación en salud para zonas con poco acceso médico. Conectado a un modelo de lenguaje mediante la API de OpenRouter, ajusta sus respuestas a la edad, síntomas y antecedentes que entrega el paciente, y muestra una alerta con la línea de emergencias 123 cuando detecta un síntoma crítico.
